# ⓪ 음식 이미지 10장 생성

너는 음식의 시각적 특징을 관찰하기 위한 참고 이미지를 생성한다.

입력 음식: {음식명}

입력된 음식 자체를 명확히 보여주는 사실적인 이미지 10장을 생성한다.
각 이미지는 사용자가 특징 분석용 이미지 하나를 선택하기 위한 후보이다.

[대상 해석]
- 입력된 단어가 일반적으로 가리키는 음식의 범위 안에서 해석한다.
- 10장 모두 입력된 단어로 부를 수 있는 음식이어야 하며, 다른 음식으로 바꾸지 않는다.
- 같은 이름 안에서 대표적인 여러 종류를 폭넓게 포함한다.
- 여러 해석이 가능하면 적용한 해석을 짧게 밝힌다.

[후보 구성]
- 10장은 종류(같은 이름의 여러 종류)와 형태·상태(통째, 자른 단면, 조각, 여러 개, 쌓음, 부서짐 등)를 섞어 서로 뚜렷하게 다른 형태를 보여준다.
- 전체 윤곽, 측면, 두께, 표면, 단면 등 서로 다른 시각 정보를 제공한다.
- 모든 사진에 동일한 구도나 배치를 반복하지 않는다.
- 단면이나 내부는 해당 음식에서 자연스럽게 확인할 수 있는 경우에 표현한다.
- 보이지 않는 내부를 임의로 발명하거나 특징을 과장하지 않는다.
- 대상의 형태를 가리는 과도한 겹침과 장식적인 연출을 피한다.

[이미지 조건]
- 음식 자체가 중심인 사실적인 사진.
- 단순한 배경과 형태를 읽을 수 있는 조명.
- 패키지, 로고, 광고 문구, 일러스트, 손, 조리 도구, 장식용 소품 제외.
- 음식의 주요 윤곽이 프레임 안에 들어오도록 한다.
- 문자, 번호, 설명문을 이미지 안에 넣지 않는다.
- 총 10장의 개별 이미지로 출력한다. 콜라주로 만들지 않는다.

우선순위:
단어 일치도 > 대표성 > 대상 명확성 > 배경 단순성 > 가시성 > 이미지 품질

생성 이미지는 실제 대상을 촬영한 관찰 자료가 아니라
AI가 생성한 참고 이미지임을 구분한다.
